## Overview

- **Period:** January 2024 – March 2024
- **Type:** Team project
- **Objective:** Develop a multiplayer game that runs in a VR environment using the Unity engine.

## Key Features

- Implemented gameplay interactions based on VR-device input.
- Built a networked multiplayer environment.
- Optimized levels of detail, meshes, and collision handling for smooth execution in VR.

## Responsibilities

- Designed the user interface and connected UI logic.
- Modified model assets and applied animations in the multiplayer environment.
- Implemented background music that changes dynamically according to the player's situation.

## Challenge

- The game could not be fully completed within the available development period.
